# ScholarLens AI

ScholarLens AI is an AI-powered research paper review system using Streamlit and LLMs.

## Features
- Research paper analysis
- Similarity comparison
- Online paper discovery
- LLM-based review agents
- Interactive academic chatbot

## Technologies Used
- Python
- Streamlit
- Ollama
- Scikit-learn
- Semantic Scholar API
- Crossref API

## Dataset Sources
- Kaggle
- IEEE Dataport
- Semantic Scholar
- Crossref

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
